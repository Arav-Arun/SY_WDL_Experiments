- Aim of the Experiment: To design and implement client-side form validation using JavaScript for the farmer registration form of the KisanSaathi Smart Irrigation Advisory portal, so that the name, mobile number, email address, plot ID, village, crop stage, soil type, irrigation method, soil moisture and registration date entered by a farmer are complete and valid before the form is submitted.

- Conclusion : JavaScript validation was added on top of the Experiment 2 portal without changing its layout or theme. Required text fields are checked using trim(), regular expressions validate the mobile number, email address and plot ID, the select menus and the irrigation radio group are checked for a selection, soil moisture is range checked between 0 and 100, and the registration date is compared with the current date so that future dates are rejected. Each failed check writes a message beside the field and highlights it, and the form is not submitted until every value is corrected.
