Irrigation Workflow

  1. Check soil moisture sensor reading for the plot
  2. Compare reading with the crop water requirement for current growth stage
  3. Fetch latest rainfall and temperature data
  4. System generates irrigation recommendation
  5. Irrigate field if water stress level is high
  6. Log irrigation event and update dashboard

Sensors Used

  • Soil Moisture Sensor
  • Temperature Sensor
  • Humidity Sensor
  • Rainfall Sensor

Crop Stages

Germination
Seed sprouting stage; requires consistent soil moisture and light irrigation.
Tillering
Multiple shoots develop from the base. moderate water requirement.
Grand Growth
Highest water demand stage, rapid stalk and leaf development.
Maturity
Water requirement decreases as the crop ripens before harvest.
